# Security baseline

- Never commit API keys, OAuth tokens, signing keys or private certificates.
- Do not place privileged server credentials in client binaries.
- Avoid logging authorization headers, tokens or personal data.
- Validate identifiers, page sizes and URLs before use.
- Apply bounded timeouts and retry limits.
- Keep dependencies updated and review security advisories.
- Use platform secure storage for user credentials when applicable.
- Provide a process for reporting security issues before public production releases.
